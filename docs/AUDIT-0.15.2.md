# Домик Николь — аудит 0.15.2

Исходная ветка: `prototype-v1-room`, commit `cf0a329`. Задание: PDF пользователя от 28.10.2026. Изменения представлены отдельным PR, без переписывания исходной ветки.

## Подтверждённые дефекты и изменения

| Дефект исходного кода | Изменение | Проверка |
|---|---|---|
| Сохранённые домики 4–6 загружались как уровень 3 (`coerceIn(0,3)`) | Границы восстановления берутся из каталога конкретного слота | Регрессионный тест всех видов и уровней |
| Питомец уменьшался примерно вдвое при входе | Постоянный размер, маршрут через вход и отдельные позы | Тест непрерывности координат 30 сочетаний; визуальная проверка отдельно |
| Движение и длительность действий зависели от FPS | Фиксированный шаг симуляции по времени кадра; пауза по Lifecycle | Тест 60/120 Hz; Android smoke-тест возврата из фона |
| Нажатие действия в домике перемещало питомца сразу на пол | Очередь команды, завершение входа, маршрут выхода | Тест прерывания визита |
| Фиолетовая линия ошейника рисовалась поверх нижней части морды собаки | Ошейник рисуется до головы; отдельные движения головы и лап | Проверка рендера; пользовательское видео целиком недоступно |
| Еда/игра/поглаживание заменялись декоративными частицами | Суставные позы, наклон головы, движение лап и игрушки | Кадры Android; художественная приёмка остаётся отдельной |
| Кнопки покупки 35–36 dp и однотипные цвета | 48 dp, цвета семейств, контрастные статусы | Кадры реальных диалогов |
| День/ночь сбрасывались после закрытия | Сохранение `night` в существующих preferences | Проверка кода; ручная проверка на телефоне ещё нужна |

## Проверки

- JVM: покупки всех 72 предметов комнаты и 55 позиций питомцев; обычная платная экономика; независимость слотов; восстановление высоких уровней; фильтрация видов; переходы; отсутствие телепортации; отсутствие обращения к некупленным домикам/мискам.
- Навигация: оба обхода кухонного стола и точка у окна; проходы к домику и миске при каждом из шести вариантов четырёх видов мебели. Геометрия кухонных препятствий не изменялась. Функции навигации вынесены из Activity для тестирования.
- Android: запуск пяти питомцев, вход в домик через касание настоящей сцены, последовательные кадры, магазин комнаты, зоомагазин при доступной вкладке, фон/возврат. Это smoke-тест, а не доказательство отсутствия любых ANR или дефектов на всех устройствах.
- CI дополнительно проверяет ZIP APK, package ID, подпись и SHA-256. Фактические результаты и кадры находятся в артефакте `Domik-Nikole-audit-evidence` соответствующего запуска Actions.

## Оставшиеся ограничения приёмки

Полное выполнение всех критериев PDF пока не заявлено.

1. Уникальные длинные сценарии ещё неполны: тоннели и умывание хомяка, исследование пруда черепахой, полноценный контакт руки Николь при поглаживании. Ходьба, сон, еда и игра используют новые позы, но нуждаются в художественной оценке на смартфоне.
2. Сохраняются существующие 30 моделей жилищ. Покрытие передними частями и совпадение входов нужно визуально проверить для каждого уровня; автоматический тест маршрута не подтверждает качество отрисовки каждого домика.
3. Гардероб в исходном проекте — заглушка; реализована только одна обучающая мини-игра со счётом яблок. Вторая дверь кухни ведёт в будущую комнату. Аудиоассетов в репозитории нет.
4. Полный пользовательский видеоотзыв не был доступен; использованы текст задания и встроенные кадры PDF. Видео работы не заменялось постановочной анимацией; предоставляются кадры настоящего Android-приложения.
5. Обновление поверх прежнего APK без потери данных не подтверждено: нужен тот же ключ подписи. Исходный workflow создавал debug APK на временном runner без явного сохранения ключа. Добавлено кеширование ключа для следующих сборок в доступной области кеша; оно не восстанавливает старый ключ и не гарантирует его доступность из другой ветки.
6. RU/DE подписи сохранены, но полный визуальный прогон немецкого интерфейса, увеличенного системного шрифта и разных телефонов ещё нужен. Производительность на физическом телефоне и длительный прогон на перегрев не измерены.

## Установка

Нужен `Domik-Nikole-preview-apk`, package `com.nikolegame.preview`, version `0.15.2` (28). Цены показаны, покупки в debug бесплатны; release использует монеты.

Если Android сообщает конфликт подписи с уже установленной тестовой версией, не удаляйте прежнее приложение ради проверки: удаление очищает локальный прогресс. Сначала необходимо согласовать перенос данных или получить прежний ключ подписи.
