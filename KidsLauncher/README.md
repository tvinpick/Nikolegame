# KidsLauncher — лаунчер для детских часов

Отдельный от игры Android-проект (Kotlin, без сторонних библиотек).
Устройство: Android 8.1 (API 27), экран 240×296, без Google-сервисов.
`minSdk 26`, `targetSdk 27`, пакет `com.nikole.kidslauncher`.

Готовый debug APK: [`dist/KidsLauncher-debug.apk`](dist/KidsLauncher-debug.apk).

## Установка
```
adb install -r dist/KidsLauncher-debug.apk
```
Появятся две иконки: «Детский лаунчер» и «Все приложения».
Нажмите «Домой» и выберите «Детский лаунчер» → «Всегда».

## Этап 1 — разведка (`AppListActivity`, иконка «Все приложения»)
- Список всех активностей `ACTION_MAIN + CATEGORY_LAUNCHER`: иконка, название, пакет.
- Тап по строке — запуск приложения.
- «Экспорт» — файл `Download/apps_ГГГГММДД_ччммсс.txt` (название, пакет, активность,
  плюс список всех HOME-активностей и модель устройства). При первом нажатии
  будет запрошено разрешение на запись в память.

## Этап 2 — лаунчер (`MainActivity`, HOME + DEFAULT)
- Сверху время и заряд батареи (⚡ — заряжается, красный — ≤15%).
- Сетка 2×2 крупных кнопок (иконка + подпись), размеры подстраиваются под экран.
- «Назад» на главном экране ничего не делает.
- **Родительский режим:** удерживать часы/верхнюю панель 5 секунд (панель
  подсвечивается) → ввод кода на цифровой клавиатуре (по умолчанию **1234**).
  - список приложений: тап выбирает/снимает, номер в жёлтом кружке = место в сетке (максимум 4);
  - «Открыть стандартный лаунчер» — находит другие HOME-активности и запускает
    (если их несколько — предлагает выбор);
  - «Лаунчер по умолчанию…» — системный экран выбора домашнего приложения (если есть в прошивке);
  - «Сменить код» — новый код вводится дважды;
  - «Все приложения» — экран этапа 1.
- Настройки хранятся в `SharedPreferences` (`launcher.xml`).
- Нет фоновых сервисов; батарея отслеживается приёмником только пока экран открыт.
  Системные приложения не изменяются.

## Сборка
**Android Studio / Gradle** (нужен доступ к google()):
```
./gradlew assembleDebug    # app/build/outputs/apk/debug/app-debug.apk
```
**Без Android SDK от Google** (так собран `dist/`): `./build-apk.sh` — использует
`aapt`, `dalvik-exchange`, `zipalign`, `apksigner` из Ubuntu, `android.jar` API 27
из Robolectric android-all 8.1.0 и Kotlin-компилятор из Maven Central.
Результат — `build-manual/KidsLauncher-debug.apk`.
