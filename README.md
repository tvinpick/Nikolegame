# Домик Николь / Nicoles Häuschen

Личная офлайн Android-игра. Kotlin, Jetpack Compose и Canvas. Нет рекламы, сетевых разрешений и реальных платежей.

## Прототип 0.15.2

Эта ветка содержит исправления по техническому заданию от 28 октября 2026 г. Полная приёмка по ТЗ ещё не завершена. См. [аудит и ограничения](docs/AUDIT-0.15.2.md).

Работают спальня и кухня, перемещение Николь касанием и поиск пути вокруг мебели, камера, холодильник, день/ночь и сезоны, выбор одного из пяти питомцев, RU/DE, локальные сохранения, магазин комнаты и отдельный магазин активного питомца. В магазине комнаты 72 позиции; у каждого питомца шесть покупаемых жилищ и три миски плюс варианты без предмета. Есть мини-игра со счётом яблок и начислением монет.

В 0.15.2:

- сохранённые домики уровней 4–6 больше не сбрасываются на уровень 3;
- движение выполняется с фиксированным шагом по времени кадра и приостанавливается в фоне;
- введены состояния поведения, независимая работа лап/головы/хвоста, лежачие и спящие позы, еда и игра;
- вход/выход не изменяют размер животного, команды из домика проходят через выход;
- ошейник собаки рисуется под головой, без полосы поверх морды;
- кнопки покупки увеличены до 48 dp; семьи товаров имеют отдельные цвета;
- добавлены регрессионные тесты и Android smoke-тест с кадрами реальной игры.

**Пока не готовы:** гардероб, дополнительные мини-игры, третья комната, звуки, полные уникальные сценарии питомцев и окончательная художественная полировка. Наличие тестов не означает проверку всех телефонов и всех визуальных сочетаний.

## APK со смартфона

1. Открой вкладку **Actions → Android APK** и успешный запуск нужного коммита.
2. Скачай артефакт **Domik-Nikole-preview-apk**, распакуй ZIP приложением «Файлы».
3. Открой `app-debug.apk`. Для установки Android может запросить разрешение этому источнику.

Preview имеет пакет `com.nikolegame.preview` и название «Домик Николь (тест)». Он устанавливается отдельно от обычного пакета `com.nikolegame`. В debug покупки бесплатны, цены остаются видны; release требует игровые монеты.

Обновление установленного preview требует того же ключа подписи. Старый workflow не сохранял ключ явно. Новый кеш помогает повторным сборкам в той же области GitHub Actions, но не восстанавливает утраченный ключ. При конфликте подписи не удаляй прежнюю игру с прогрессом: сначала нужен перенос данных или прежний ключ.

## Сборка и проверки

Конфигурация проекта: JDK 17, Gradle 9.4.1, Android Gradle Plugin 9.2.1, Compose BOM 2026.09.00, compileSdk 37, targetSdk 35, minSdk 26.

```sh
gradle :app:testDebugUnitTest -Ppreview
gradle :app:assembleDebug -Ppreview
gradle :app:assembleDebugAndroidTest -Ppreview
```

GitHub Actions собирает оба debug-пакета, проверяет структуру/подпись preview и запускает smoke-тест на Android 35. Артефакт **Domik-Nikole-audit-evidence** содержит результаты JVM-тестов, сведения об APK и, если эмулятор успешно запущен, кадры и результаты инструментальных тестов.

## Структура

- `MainActivity.kt`: сцена, UI, сохранения и игровой цикл.
- `RoomNavigation.kt`: геометрия препятствий и поиск пути обеих комнат.
- `PetLife.kt`: состояния и маршруты питомца.
- `PetPoseArt.kt`: отдельные части тела и позы пяти видов.
- `PetHabitatsDetailed.kt`, `PetAccessories.kt`: модели домиков, миски, каталог.
- `RenovationShop.kt`, `PetShop.kt`: магазины.
- `RenovationPurchase.kt`: общая логика покупки без реальных платежей.

Сохранения используют прежний файл SharedPreferences `nicole_save` и прежние ключи предметов. Автоматического переноса между обычным и preview-пакетом нет.
