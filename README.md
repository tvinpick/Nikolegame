# Мой сказочный домик

Уютная 2.5D-игра-комната для ребёнка 6 лет: девочка, кошка и собака, свободная перестановка мебели, магазин за монеты, уход за питомцами, 5 видов развивающих занятий (RU/DE), времена года и погода за большим окном. Без рекламы, платежей, аккаунтов и сети.

* Движок: **Godot 4.7.2 Stable** (зафиксирован в `ENGINE_VERSION` и `.github/workflows/android.yml`), рендерер Compatibility.
* Платформа: Android, горизонтальная ориентация, minSdk 24 (Android 7), targetSdk 36.
* Два APK: обычный `com.nikole.skazochnydomik` и тестовый `com.nikole.skazochnydomik.test` (разные сохранения, можно ставить оба).

> **Статус: первая функциональная версия. На реальном телефоне НЕ проверена, сборка APK в CI ещё не запускалась.** См. «Что не проверено».

## Как получить APK с телефона (без компьютера)

1. Откройте репозиторий в браузере телефона или в приложении GitHub → вкладка **Actions**.
2. Выберите последний зелёный запуск **Android APK** для нужной ветки.
3. Внизу страницы в блоке **Artifacts** нажмите `skazochny-domik-apk-…` — скачается ZIP.
4. Откройте ZIP в приложении «Файлы» → внутри:
   * `skazochny-domik-<версия>-debug.apk` — обычная игра;
   * `skazochny-domik-TEST-<версия>-debug.apk` — тестовая сборка (режим разработчика всегда доступен).
5. Нажмите на APK → Android попросит разрешить установку из этого источника → «Разрешить» → «Установить».
6. Запустите, выберите котика и собачку. Закройте и откройте снова — монеты и расстановка должны сохраниться.

Отчёт тестов, логи и скриншоты рендера — в артефакте `reports-<номер>`.

### Обновление без потери прогресса
Android ставит новую версию поверх старой только при подписи **тем же ключом**.
* Если в Secrets задан `ANDROID_DEBUG_KEYSTORE_B64` — ключ постоянный, обновления ставятся поверх.
* Без секрета CI создаёт ключ сам и хранит его в кэше Actions; кэш может исчезнуть (≈7 дней без сборок). Тогда перед удалением старой версии сделайте копию: «Для взрослых → Копия → Сделать копию и поделиться», а после установки — «Восстановить из файла».

Секреты добавляются с телефона: Settings → Secrets and variables → Actions → New repository secret. Для release-сборки: `ANDROID_RELEASE_KEYSTORE_B64`, `ANDROID_RELEASE_ALIAS`, `ANDROID_RELEASE_PASSWORD`. Ключи в git не хранятся.

## Режим разработчика и ZIP-отчёт с телефона
1. Нижняя серая кнопка бокового меню («для взрослых») → удерживать 3 с → решить пример.
2. «Разработчик» → включить → «Открыть панель разработчика».
3. «● Запись» — Android покажет системный запрос (перед каждой записью). Микрофон не используется: звук игры записывается внутри Godot и вклеивается в MP4 Kotlin-плагином.
4. Во время игры откройте панель → «Отметить ошибку» (скриншот, состояние сцены, время в видео).
5. «Собрать ZIP-отчёт» → снимите галочки с лишних файлов → «Поделиться» (Telegram, почта, Диск).

Состав `bug-report-YYYYMMDD-HHMMSS.zip`: `video.mp4`, `events.jsonl`, `performance.csv`, `errors.log`, `device.json`, `screenshots/`, `report.txt`, `test_scene_state.json`; если склейка звука не удалась — дополнительно `game_audio.wav`, и это явно написано в `report.txt`. Ничего не отправляется автоматически.

## Управление
* Тап по полу — девочка идёт. Свайп — камера, щипок — зум до 2×.
* Тап по предмету — крупные значки действий (сесть, спать, читать, учиться, есть, насыпать корм, включить…).
* Тап по питомцу — 4 потребности + играть / подойти / погладить / взять на руки / идти к предмету.
* Мяч можно перетащить и бросить. Перестановка — отдельный режим (кнопка со стрелками): двигать, отразить, отменить, убрать в сундучок.
* Учёба: стол → «учиться» → девочка отодвигает стул, садится → открывается тетрадь.

## Структура
```
scenes/main.tscn               точка входа (scripts/main.gd)
scripts/core/                  контент, состояние, локализация, векторное рисование
scripts/room/                  комната, камера, окно/параллакс, навигация, время/погода
scripts/characters/            девочка, кошка/собака, игрушки (скелеты, позы, IK)
scripts/interaction/           мебель, профили взаимодействий, резервирование, перестановка
scripts/inventory/economy.gd   единственное место, меняющее монеты и владение
scripts/save/                  атомарные сохранения, резервная копия, миграции
scripts/learning/              генераторы упражнений, адаптация, тетрадь
scripts/diagnostics/           журнал событий, метрики, отладочный слой, ZIP, мост к плагину
scripts/ui/                    HUD и экраны (магазин, гардероб, питомцы, погода, взрослые, разработчик)
content/                       каталог, профили, породы, гардероб, экономика, учебные данные RU/DE
i18n/strings.json              строки интерфейса RU/DE
android/plugins/recorder/      Kotlin-плагин записи (MediaProjection, Android plugin v2)
addons/game_recorder/          регистрация плагина для Gradle-экспорта
tests/                         headless-тесты
tools/gen_audio.py             синтез всех звуков и музыки
```

Запуск тестов: `godot --headless --path . -s tests/test_runner.gd`.

## Что проверено реально (Linux, Godot 4.7.2, без телефона)
* Импорт проекта без ошибок скриптов.
* 35 автоматических тестов зелёные: каталог/профили, RU/DE, экономика (атомарность, дубли, сундук, откат часов), сохранения (порча, прерванная запись, миграция v1→v3, бэкап), учёба (все категории × уровни × языки), правила расстановки и **поведение**: 5 циклов «лечь спать → проснуться», 3 цикла «взять кота → экстренная команда → поставить», перенос дивана из-под сидящей девочки.
* Сцены отрендерены (Xvfb/OpenGL) и просмотрены глазами: комната, сон, чтение на диване, стол со спины, кот на руках, ночь со снегом, магазин, гардероб, тетрадь.

## Что НЕ проверено
* Сборка APK в GitHub Actions не запускалась (push в репозиторий был недоступен). Рабочий процесс написан под версии из шаблона Godot 4.7.2 (AGP 8.6.1, compileSdk 36, build-tools 36.1.0, NDK 29) — первая сборка может потребовать правок.
* Запуск на Android-устройствах, включая Xiaomi 12T Pro: FPS, касания, вырезы, запись экрана, склейка звука, «Поделиться», системный выбор файла.
* Озвучка: офлайн-синтез речи устройства (нужны голоса RU/DE); записанных дикторских файлов нет.
